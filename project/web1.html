The Brief

A site that reads as one profile, not six pages

Designed and built as a lightweight, zero-dependency static site — hosted on GitHub Pages, driven entirely by plain HTML, CSS, and JavaScript. Every page shares the same header, footer, and visual language so it feels like a single coherent presence rather than a stitched-together set of documents.

Design Decisions

Three calls that shaped everything else

01

No framework, no build step

Plain HTML, CSS, and JavaScript, served directly by GitHub Pages. Nothing to install, nothing to compile — a page can be edited and pushed live in minutes, even from a phone browser.

02

One shell, six pages

A single shared navigation and footer pattern repeated across every page, so the site never feels like it was assembled from disconnected parts — even though each page was built independently.

03

Built to be forked

Personal details were pulled into a small, clearly marked set of spots from the start, so handing the repo to another researcher is a find-and-replace job, not a rewrite.
