AUTONOMOUS UTILITY ROBOTIC ASSISTANT

A robot that reasons
before it moves.

AURA pairs an on-device AI brain with a personality-driven hardware layer and a control app you can reach from a laptop, a phone, or a browser — built as a working demonstration of full-stack, embedded, and AI engineering.

What AURA does

04 CORE SYSTEMS
SYS.01

Perception & autonomy

AURA reads its surroundings through onboard sensors and decides how to move through them, rather than following a fixed script — the foundation for everything else it does.

SENSORSNAVIGATIONROBOTICS
SYS.02

An AI brain, running locally

An Ollama-powered language model gives AURA reasoning and conversation on-device — no cloud round-trip required to hold a conversation or decide what to do next.

OLLAMAON-DEVICE AIPYTHON
SYS.03

Command it from anywhere

A Robot Control Center reaches AURA from Windows, Android, or the web, all talking to the same Raspberry Pi backend — so it isn't tied to one laptop or one screen.

WINDOWSANDROIDWEB CLIENT
SYS.04

Expressive hardware

An Arduino-driven personality layer, written in embedded C++, gives AURA physical reactions and expression — the difference between a machine and something with character.

Spec sheet

AURA-B1
Full name Autonomous Utility Robotic Assistant — built as a career-asset project, not a hobby demo.
Compute core Raspberry Pi running the backend API that every client talks to.
AI reasoning Local language model served through Ollama for on-device conversation and decision-making.
Personality layer Arduino-based, written in embedded C++, drawing on a companion personality-robot build.
Control surfaces Robot Control Center available on Windows and Android, plus a browser-based web client — same backend, three front doors.
Disciplines shown Software engineering, robotics, applied AI, Arduino/embedded systems, and drone-adjacent control work.
Built for Demonstrating engineering ability directly to companies, interviewers, and technical teams.
